    Cosa Scegliere?¶

    Minimo¶

    • Avvio rapido
    • Funziona con i default
    • Configurazione minima

    Usa per: prima esecuzione, test.

    Avanzato¶

    • Concurrency (cancella duplicati)
    • Filtro PR da fork
    • Lingua personalizzata
    • Protezione timeout

    Usa per: produzione.

    Consiglio¶

    1. Inizia con l'esempio minimo
    2. Assicurati che funzioni
    3. Aggiungi le opzioni necessarie dall'esempio avanzato
